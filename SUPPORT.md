# Support

| Need | Where |
| --- | --- |
| A question or a discussion | [Discord](https://discord.gg/qCVqhXtSzR) |
| A bug or a feature request | The issue tracker of the repository concerned |
| A security problem | admin@orthrus.cc, privately; see [SECURITY.md](SECURITY.md) |
| Anything else | admin@orthrus.cc or [orthrus.cc](https://orthrus.cc) |

A useful bug report names the versions involved (Minecraft, loader, the mod, related mods) and
includes the log and the steps that reproduce it.
