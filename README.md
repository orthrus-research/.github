# Orthrus Research: shared files

The organization profile and the community files that every Orthrus Research repository
inherits unless it provides its own.

| Path | Contents |
| --- | --- |
| `profile/README.md` | The profile shown at [github.com/orthrus-research](https://github.com/orthrus-research) |
| `AI.md` | How Orthrus Research uses AI assistants, and the terms for contributors |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Defaults for every repository |
| `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` | Default issue forms and pull request template |
| `assets/orthrus-mark.svg` | The Orthrus Research mark |
| `assets/banners.py` | Draws the mark and the repository banners: `python assets/banners.py OUT NAME` |
